The Steam Deck builds the game again.

**No game data is included.** You need your own disc: `Harvest Moon: Animal Parade (USA)`, `RBIEE9`.

> **Experimental.** This port is still in an early stage: graphical glitches can happen, above all with the free camera. If something looks wrong or the game stops, please open an issue with the newest file in `UserData/Logs`.

| **Android** (11 or newer, 64-bit, Vulkan) | Still the APK from [v0.2.1](https://github.com/RodoLy/HarvestMoonAnimalParadeRecomp/releases/tag/v0.2.1) for now; the changes since then come to Android in a later APK |

Updating: with v0.2.3 or v0.2.4, the launcher's Game tab shows **Update to v0.2.5**: one click and it's done. From older versions, unzip the new package over the old folder. Your saves and settings in `UserData` stay either way.

### What's new

- **Linux and Steam Deck**: building the game stopped at the very end ("ninja: build stopped: subcommand failed") on systems without their own C and C++ development files, like the Steam Deck. The Linux package now brings newer ones, and the C++ library goes inside the game. A folder where the build already failed is configured again by itself. Linux needs a system from 2023 on (glibc 2.38: current SteamOS, Ubuntu 24.04, Fedora 39, Debian 13).
- Windows and macOS have no changes; their packages are the same as v0.2.4 with the new version number.

For the text boxes in Wide and the controller's buttons in RecompLauncher, see [v0.2.4](https://github.com/RodoLy/HarvestMoonAnimalParadeRecomp/releases/tag/v0.2.4).

Linux necesita un sistema de 2023 en adelante (glibc 2.38: SteamOS actual, Ubuntu 24.04, Fedora 39, Debian 13).
- Windows y macOS no tienen cambios; sus paquetes son los mismos de la v0.2.4 con el número de versión nuevo.
