The game now sets itself up from RecompLauncher.

**No game data is included.** You need your own disc: `Harvest Moon: Animal Parade (USA)`, `RBIEE9`.

> **Experimental.** This port is still in an early stage: graphical glitches can happen, above all with the free camera. If something looks wrong or the game stops, please open an issue with the newest file in `UserData/Logs`.

### Download

| | |
|---|---|
| **Windows x64** | `HarvestMoonAnimalParade-windows-x64.zip` |
| **Windows on ARM** (Snapdragon X) | `HarvestMoonAnimalParade-windows-arm64.zip` |
| **Linux x86-64** | `HarvestMoonAnimalParade-linux-x86_64.tar.gz` |
| **Linux ARM64** (Raspberry Pi 5, Nintendo Switch with switchroot Linux) | `HarvestMoonAnimalParade-linux-aarch64.tar.gz` |
| **macOS** (Apple Silicon) | `HarvestMoonAnimalParade-macos-arm64.zip` |
| **Android** (11 or newer, 64-bit, Vulkan) | `HarvestMoonAnimalParade-Android.apk`, the same as in v0.2.0: nothing changed for Android |

Updating from v0.2.0: unzip the new package over the old folder. Your saves and settings in `UserData` stay; the launcher builds the game again the first time.

### What's new

- **RecompLauncher**: every computer package carries a `recomplauncher.json`. In [RecompLauncher](https://recomplauncher.com) you drop in your disc image, it is checked (it has to be `RBIEE9`), the game is built with no window while the launcher shows how far it is, and Play starts the game directly. The mods and cheats are on the game's page, and the saves are backed up after every session. Details: [docs/RECOMPLAUNCHER.md](https://github.com/RodoLy/HarvestMoonAnimalParadeRecomp/blob/main/docs/RECOMPLAUNCHER.md).
- Everything from [v0.2.0](https://github.com/RodoLy/HarvestMoonAnimalParadeRecomp/releases/tag/v0.2.0) is here too: the free camera, romance for everyone, shorter loading screens, faster walking and actions (the animals too), cheats, the clearer launcher, and Linux, macOS and Android.

Known issues: the free camera comes close to the player near the sea; in languages other than English the title screen shows the Japanese logo.

El juego ahora se prepara solo desde RecompLauncher.

**No incluye datos del juego.** Necesitas tu propio disco: `Harvest Moon: Animal Parade (USA)`, `RBIEE9`.

> **Experimental.** El port todavía está en una etapa temprana: pueden aparecer fallos gráficos, sobre todo con la cámara libre. Si algo se ve mal o el juego se detiene, abre un issue con el archivo más nuevo de `UserData/Logs`.

Descargas: el zip de **Windows x64** o **arm64**, el de **Linux** (x86-64 o ARM64), el de **macOS** (Apple Silicon) o el **APK** de Android, el mismo de la v0.2.0 (para Android no cambió nada).

Para actualizar desde la v0.2.0: descomprime el paquete nuevo encima de la carpeta vieja. Tus partidas y ajustes de `UserData` se quedan; el launcher vuelve a compilar el juego la primera vez.

Qué hay de nuevo:

- **RecompLauncher**: cada paquete de computadora trae un `recomplauncher.json`. En [RecompLauncher](https://recomplauncher.com) sueltas la imagen de tu disco, se revisa (tiene que ser `RBIEE9`), el juego se compila sin ventana mientras el launcher muestra el avance, y Jugar abre el juego directo. Los mods y los trucos están en la página del juego, y las partidas se respaldan después de cada sesión.
- Todo lo de la [v0.2.0](https://github.com/RodoLy/HarvestMoonAnimalParadeRecomp/releases/tag/v0.2.0) sigue aquí: cámara libre, amor para todos, pantallas de carga más cortas, caminar y actuar más rápido (también con los animales), trucos, el launcher más claro, y Linux, macOS y Android.

Problemas conocidos: cerca del mar la cámara libre se acerca al jugador; en idiomas que no son inglés, la pantalla de título muestra el logo japonés.
