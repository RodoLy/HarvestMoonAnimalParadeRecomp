# Where this game keeps what WiiCompiled's native audio looks for at Mario Kart Wii's addresses.
# Dónde guarda este juego lo que el audio nativo de WiiCompiled busca en las direcciones de Mario Kart Wii.
#
# The columns are those of RBIEE9-os-addresses.txt; tests/test_wiicompiled_addresses.py checks every row.
# Las columnas son las de RBIEE9-os-addresses.txt.
#
# WiiCompiled runs AX translated and replaces what is below it (DSP and AI). Its DSP builds AX's task
# itself, so it needs the task, AX's microcode and the four callbacks the task points at. In this game
# __AXOutInitDSP (0x80270AB0) fills the same task the same way: the same lengths (0x40 bytes of DRAM, at
# DSP address 0xCD2), the DRAM 0x60 bytes after the task, and the callbacks in the same order.
#
# covers: runtime/src/hle/audio

# ---------------------------------------------------------------- AXOut.c: the callbacks of AX's DSP task
0x80126948  0x80270A20  __AXDSPInitCallback (the task's init_cb, at 0x28)  name
0x80126954  0x80270A30  __AXDSPResumeCallback (res_cb, at 0x2C)         name
0x801269A8  0x80270A90  __AXDSPRequestCallback (done_cb, at 0x30)       name
0x801269B8  0x80270AA0  the next function, four bytes long (req_cb, at 0x34); neither map names it  0x80270AB0
