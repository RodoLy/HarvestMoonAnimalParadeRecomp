# Where this game keeps what WiiCompiled's native OS looks for at Mario Kart Wii's addresses.
# Dónde guarda este juego lo que el OS nativo de WiiCompiled busca en las direcciones de Mario Kart Wii.
#
# WiiCompiled's runtime/src/hle/os names 25 addresses of Mario Kart Wii (PAL, RMCP01) with MKW_GADDR():
# functions it calls and variables of the SDK it reads and writes. To use those native functions here,
# each needs this game's address. docs/NATIVE_RUNTIME.md explains why; tests/test_wiicompiled_addresses.py
# checks every row against main.dol.
#
# El runtime de WiiCompiled nombra 25 direcciones de Mario Kart Wii en su OS. Para usar esas funciones
# nativas aquí, cada una necesita la dirección de este juego. La prueba comprueba cada fila contra main.dol.
#
# covers: runtime/src/hle/os runtime/src/fiber_manager.cpp
#
# Columns / Columnas:
#   1. the address in Mario Kart Wii (PAL), as MKW_GADDR() writes it
#   2. the address in this game (RBIEE9), or "-" when this game has no such thing
#   3. what it is
#   4. the evidence: a function of this game that touches the address (for a variable), or "name" (for a
#      function: symbols.txt gives it that name), or "held at 0x..." (main.dol holds the address in that
#      word), or "-" with the reason in column 3
#
# A variable's evidence is a function of this game that loads it, stores it or puts its address
# together. The SDK's variables of one source file sit in the same order in both games, so when the
# evidence alone does not say which of two neighbours is which, the order does: that is said in column 3.
