# Where this game keeps what WiiCompiled's native GX looks for at Mario Kart Wii's addresses.
# Dónde guarda este juego lo que el GX nativo de WiiCompiled busca en las direcciones de Mario Kart Wii.
#
# The columns are those of RBIEE9-os-addresses.txt; tests/test_wiicompiled_addresses.py checks every row.
# Las columnas son las de RBIEE9-os-addresses.txt.
#
# The big variables of GX sit in .bss in the same order and at the same distances in both games, from
# the FIFO object GXInit uses to the saved CPU FIFO of the display lists; the small ones (.sbss) too,
# each 0x332E058 bytes further on than in Mario Kart Wii.
#
# covers: runtime/src/hle/gx

0x8016ED94  0x80279660  GXFinishInterruptHandler                        name
0x8016ED50  0x80279610  GXSetDrawDoneCallback (only Mario Kart Wii's EGG code calls it from WiiCompiled)  name
